СРАВНЕНИЕ ПОДПИСЧИКОВ — WEB/PWA

Файлы:
- index.html — приложение
- manifest.webmanifest — установка как приложение
- sw.js — офлайн-кэш после первого открытия
- icon-*.png — иконки

Публикация:
1. Создайте репозиторий на GitHub.
2. Загрузите все эти файлы в корень репозитория.
3. В Settings -> Pages включите GitHub Pages для ветки main / root.
4. Откройте полученный адрес в Safari на iPhone.
5. Safari -> Поделиться -> На экран Домой.

Важно:
CSV-файлы не отправляются приложением на сервер. Сравнение выполняется
локально в браузере. Сам сайт при этом доступен по URL, поэтому не
публикуйте в репозитории сами CSV-файлы.
